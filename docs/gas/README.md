# 「へんなことば」報告をスプレッドシートに集める（GAS の設定手順）

アプリのクリア画面で 🚩 を押すと、その熟語が報告されます。ここで作る URL を「おうちのひと メニュー」に貼ると、Google スプレッドシートに自動で溜まります。所要 5 分程度。Google アカウントでのログインが必要なので、この手順はご自身で行ってください。

1. Google ドライブで新しいスプレッドシートを作る（名前は「パンしりとり報告」など）。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 開いたエディタの内容をすべて消し、同じフォルダの `Code.gs` の内容を貼り付けて保存する。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類の選択（歯車）→「ウェブアプリ」。
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」を押し、アクセス承認を進める（「このアプリは Google で確認されていません」→「詳細」→「（安全ではないページ）に移動」→ 許可）。
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー。
7. リポジトリの Secret `REPORT_URL` に登録する（`gh secret set REPORT_URL --body "<URL>"`、または GitHub の Settings → Secrets and variables → Actions）。次の公開ビルドから全端末の初期値になる。個別の端末だけ変えたいときは「おうちのひと メニュー」→「報告の送り先」に貼る。

## URL を作り直したいとき（漏れた・いたずらが来た）

Apps Script の「デプロイ」→「新しいデプロイ」で新しい URL を作り、古いデプロイは「デプロイを管理」からアーカイブすると、古い URL は無効になります。新しい URL を Secret `REPORT_URL` に入れ直して push すれば切り替わります。

## コードを更新したいとき

`Code.gs` を貼り直して保存したあと、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョンを「新バージョン」にして「デプロイ」。この手順なら URL は変わりません。

動作確認: 手順 6 の URL をブラウザで開くと `panshiri report endpoint OK` と表示されれば成功です。

## 報告が来たら

スプレッドシートの `reports` シートに 1 行ずつ溜まります。除外したい語は `data/work/overrides.json` に次のように書いて `npm run data` → `npm run build` → デプロイすると反映されます。

```json
{ "年金": { "k": 0 }, "赤字": { "k": 3 } }
```

`k` は 0 = 出さない、1 = 低学年から、2 = 高学年から、3 = 中学カテゴリのみ、です。
