# 小1の娘のために、漢字しりとりアプリを1日で作って公開した話

> note 用の下書き。公開前に本人の言葉に直してください。子どもの名前は出さず「娘」「息子」で通しています。

---

## きっかけ

小学1年生の娘が漢字を習い始めた。ドリルは3日で飽きる。でも「しりとり」は飽きない。
それなら、漢字の熟語でしりとりをするゲームを作ればいいのでは、と思った。

条件は3つ。

- 娘が一人で遊べること。読めない漢字があっても止まらないこと
- 小5の息子も一緒に遊べること。学年が違っても同じアプリで
- タブレットで、家でも外でも、無料で

日曜の午後に要件を話し始めて、夜には家族で遊んでいた。作ったのは Claude と私で、コードはほぼ全部 Claude が書いた。私がやったのは「何を作るか」を決めることと、途中で気になった点を指摘することだった。

## できたもの

**パンしりとり** https://shiritori.ak-base.com/

画面に漢字のタイルが並ぶ。隣どうしが二字熟語になるように一列に並べる。
たとえば「学 → 校 → 長 → 男」なら、学校・校長・長男。前の熟語の最後の字が次の熟語の最初の字になる。しりとりだ。

- レベル1〜5。3枚から始まり、最後は10枚の中から7枚を選んでつなぐ
- 漢字の範囲は7段階。小1まで、小2まで……中3まで。常用漢字2136字を配当学年で分けた
- 生年月日を入れると学年が決まり、その学年の漢字から始まる。上の学年はクリアしていくと開く
- 間違えても減点なし。相棒のキャラクターが首をかしげるだけ
- できた熟語は読み上げてくれる。まだ読めない漢字でも遊べる
- スコアアタックはレベル1〜5を1問ずつ通しで解いて得点を競う。兄妹で同じタブレットを使うので、端末の中にランキングが残る
- 相棒は、以前作った「パン占い」の12体のパンの申し子。生年月日から一体が決まる

## 作り方で決めたこと

**正解は1つに限定しない。** 漢字の組み合わせは別の並べ方でも全部熟語になることが多い。辞書にある熟語ならどの順番でも正解にした。「正しいのに不正解」は子どものやる気を一番くじく。

**罰を作らない。** 制限時間なし、減点なし。ヒントは次に置けるタイルを光らせる。

**データは端末の外に出さない。** 名前も生年月日も進捗も、タブレットのブラウザの中にだけ保存する。サーバーはない。GitHub Pages に置いた静的なページだけで動く。費用はゼロ。

## いちばん大変だったのは辞書

ゲームのコードより、語彙のデータに時間がかかった。

- 漢字の学年は、文部科学省の学年別漢字配当表（KANJIDIC2 経由）
- 熟語の候補は、公開辞書の JMdict から二字熟語を約48,000語抽出し、使用頻度で約14,000語に絞った
- それを Claude で1語ずつ「子どもに見せてよいか」「何年生なら分かるか」を判定し、ひらがなの短い意味文も付けた
- 最初の判定は甘く、「先見」「黒地」「今夏」のような新聞語が低学年に混ざった。娘に遊ばせたらすぐ分かった。そこで小学生カテゴリの8,000語を、より厳しい基準でもう一度全部判定し直した。小1で出す語は328語から126語まで減った。「学校・天気・大人・青空・花火・七夕・玉子」。これが正しい顔ぶれだと思う
- それでも漏れは出るので、遊んでいる途中に「へん？」ボタンを付けた。押すと Google スプレッドシートに溜まる。次に直すときの材料になる

## 使った道具

- Vite + TypeScript の静的サイト（PWA。ホーム画面に追加すればアプリのように起動する）
- GitHub Pages + GitHub Actions（push すれば自動で公開）
- Google Apps Script（「へんなことば」報告の受け口）
- Google アナリティクス
- Claude（要件定義の相談相手、コード、14,000語の判定、意味文の生成）

## やってみて思ったこと

「作る」の手間がほぼ消えると、残るのは「何を作るか」と「本当にそれで良いか」を見ることだけになる。今回いちばん価値があった私の仕事は、娘の横に座って、画面に出てきた熟語を見て「これは小1には変だ」と言ったことだった。

娘は今日も「きょうの1もん」をやってから寝た。息子はスコアアタックの最高点を更新しようとしている。作った甲斐はあった。
